{{/* Is this nav or card target genuinely new? See data/nav_new.yaml. Input (dict), one date source: "key" badge key (always) "section" newest page date in that content section "page" date of that single page (e.g. "/for/engineers") otherwise data/nav_new.yaml `added` date for "key" (external links) Returns (dict "new" bool "key" string).
