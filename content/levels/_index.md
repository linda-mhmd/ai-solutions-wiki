Five progressive levels. Each builds directly on the last. You can start anywhere, but the sequence is designed so that every concept makes the next one easier.

- [Level 0: The Foundation](/levels/level-0/): hardware, operating systems, and networks
- [Level 1: How Code Works](/levels/level-1/): terminals, file systems, and code structure
- [Level 2: Managing Work](/levels/level-2/): version control, Git, GitHub, and open source
- [Level 3: The Infrastructure](/levels/level-3/): databases, servers, cloud, and APIs
- [Level 4: AI and Building](/levels/level-4/): language models, vibe coding, and production AI
